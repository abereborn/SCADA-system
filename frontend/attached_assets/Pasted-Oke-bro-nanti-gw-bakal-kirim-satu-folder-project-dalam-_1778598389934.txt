1. REFACTOR STRUKTUR COMPONENT

* Jangan taruh logic component besar langsung di file View/Page utama.
* Semua component dipisah ke folder/component masing-masing.
* File view/page cukup:

  * import component
  * panggil component
* Jadi kalau mau edit card/navbar/footer/widget tinggal buka file component terkait saja.

Contoh yang gw mau:

* components/landing/Navbar.tsx
* components/landing/HeroSection.tsx
* components/landing/FeatureGrid.tsx
* components/landing/SystemStatusWidget.tsx

* dll
