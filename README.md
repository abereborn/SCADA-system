# 📌 Overview

SCADA System Dashboard is a modern web-based monitoring interface inspired by industrial SCADA (Supervisory Control and Data Acquisition) systems.

This project focuses on:

* 📊 Realtime monitoring dashboard
* ⚡ Device and sensor visualization
* 🚨 Alert management system
* 📈 Data reports and analytics
* ⚙️ System configuration panel
* 📱 Fully responsive mobile interface
* 🎨 Modern futuristic UI/UX

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/abereborn/SCADA-system.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd SCADA-system
```

---

## 3️⃣ Install Dependencies

Using npm:

```bash
npm install
```

Or using yarn:

```bash
yarn install
```

---

## 4️⃣ Run Development Server

Using npm:

```bash
npm run dev
```

Or using yarn:

```bash
yarn dev
```

---

## 5️⃣ Open Browser

Open the following URL in your browser:

```bash
http://localhost:5173
```

---

# 🏗 Production Build

To create production build:

```bash
npm run build
```
